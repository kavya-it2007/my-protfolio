# Kavya S - Portfolio

A modern responsive portfolio built with HTML, CSS and JavaScript.

## Files
- index.html
- style.css
- script.js
- assets/

## Before publishing
Replace the sample resume information in `index.html` with your actual:
- Email
- GitHub
- LinkedIn
- College/school
- Education details
- Experience
- Projects
- Certificates
- Profile photo

Your profile image is already included at:
`assets/profile.jpg`

## Run
Open `index.html` in a browser.
